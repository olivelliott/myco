**Migration 5: `add_temporal_columns`**
Adds temporal versioning columns to observations:
```sql
ALTER TABLE observations ADD COLUMN valid_from TEXT DEFAULT NULL;
ALTER TABLE observations ADD COLUMN valid_until TEXT DEFAULT NULL;
```
Then unconditionally:
```sql
CREATE INDEX IF NOT EXISTS idx_observations_valid_from ON observations(valid_from);
CREATE INDEX IF NOT EXISTS idx_observations_valid_until ON observations(valid_until) WHERE valid_until IS NOT NULL;
```

**Migration 6: `add_decay_columns`**
Adds decay/access tracking to observations:
```sql
ALTER TABLE observations ADD COLUMN last_accessed_at TEXT DEFAULT NULL;
ALTER TABLE observations ADD COLUMN decay_exempt INTEGER NOT NULL DEFAULT 0;
ALTER TABLE observations ADD COLUMN reinforcement_count INTEGER NOT NULL DEFAULT 1;
```
Then unconditionally:
```sql
CREATE INDEX IF NOT EXISTS idx_observations_last_accessed ON observations(last_accessed_at);
```

**Migration 7: `add_relationship_strength`**
Adds strength scoring to relationships:
```sql
ALTER TABLE relationships ADD COLUMN strength REAL NOT NULL DEFAULT 1.0;
ALTER TABLE relationships ADD COLUMN reinforcement_count INTEGER NOT NULL DEFAULT 1;
```

**Migration 8: `add_entity_merged_into`**
Adds soft-delete merge tracking to entities:
```sql
ALTER TABLE entities ADD COLUMN merged_into TEXT DEFAULT NULL;
```
Then unconditionally:
```sql
CREATE INDEX IF NOT EXISTS idx_entities_merged_into ON entities(merged_into) WHERE merged_into IS NOT NULL;
```

IMPORTANT: Each ALTER TABLE must be in its own try/catch because SQLite stops at the first error in a multi-statement exec. Wrap each individual ALTER in try/catch, then run all CREATE INDEX statements unconditionally after.

valid_from?: string | null;         // ISO 8601 — when this fact became true
valid_until?: string | null;        // ISO 8601 — when this fact was superseded (NULL = current)
