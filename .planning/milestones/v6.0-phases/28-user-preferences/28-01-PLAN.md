    **2. Add `promotePreference()` to `packages/mcp-server/src/tools.ts`:**

    Place it after `rememberEntity()` (around line 206). Logic:

    ```typescript
    /**
     * Check if a user_preference entity should be promoted to global scope.
     * Called after rememberEntity() when entity_type is 'user_preference'.
     *
     * Promotion triggers:
     * 1. Same preference name exists on 2+ distinct projects -> merge into global
     * 2. Caller passes project=null explicitly -> already global, just update metadata
     *
     * On promotion:
     * - Pick one entity as the "winner" (prefer existing global, else first found)
     * - Set winner's project=NULL
     * - Set winner's metadata.source_projects to merged list of all projects
     * - For all other entities with same name+type: set merged_into=winner.id
     * - Update all active observations on winner with metadata.source_projects
     */
    export function promotePreference(
      db: Database.Database,
      stmts: MycoStatements,
      entityName: string,
      currentProject: string | null,
    ): { promoted: boolean; globalEntityId?: string; sourceProjects?: string[] } {
    ```

    Implementation details:
    - Query `selectPreferencesByNameAcrossProjects` with entityName
    - Collect all matching entities and their projects
    - If only one entity exists AND it has a non-null project, return `{ promoted: false }` — not enough corroboration
    - If 2+ entities exist with distinct projects (or one is already global):
      - Choose winner: prefer the entity with `project IS NULL`, else the one with more observations, else the first
      - Collect all unique non-null projects from all entities into `sourceProjects` array
      - In a `db.transaction()`:
        - Update winner: `updateEntityProject(NULL, now, winnerId)`, `updateEntityMetadata(JSON.stringify({ source_projects: sourceProjects }), now, winnerId)`
        - For each active observation on winner: `updateObservationMetadata(JSON.stringify({ source_projects: sourceProjects }), obsId)`
        - For each loser entity: `stmts.setEntityMergedInto.run(winnerId, loserId)` + move their observations to winner entity (update entity_id)
      - Return `{ promoted: true, globalEntityId: winnerId, sourceProjects }`
    - If caller passed `project=null` (already global), just ensure metadata.source_projects includes whatever info is available
