**Export: `levenshtein(a: string, b: string): number`** — Standard DP algorithm, 14 lines:
```typescript
export function levenshtein(a: string, b: string): number {
  const m = a.length, n = b.length;
  const dp: number[][] = Array.from({ length: m + 1 }, (_, i) =>
    Array.from({ length: n + 1 }, (_, j) => (i === 0 ? j : j === 0 ? i : 0))
  );
  for (let i = 1; i <= m; i++) {
    for (let j = 1; j <= n; j++) {
      dp[i][j] = a[i - 1] === b[j - 1]
        ? dp[i - 1][j - 1]
        : 1 + Math.min(dp[i - 1][j], dp[i][j - 1], dp[i - 1][j - 1]);
    }
  }
  return dp[m][n];
}
```

**Export: `isMergeCandidate(nameA: string, nameB: string): boolean`** — Returns true if Levenshtein distance <= 2 OR case-insensitive exact match:
```typescript
export function isMergeCandidate(nameA: string, nameB: string): boolean {
  const a = nameA.toLowerCase().trim();
  const b = nameB.toLowerCase().trim();
  return a === b || levenshtein(a, b) <= 2;
}
```

**Export: `detectContradiction(db, entityId, factText, threshold?): Promise<boolean>`** — Embed the fact text via `embedText()`, then run KNN on `vec_embeddings` filtered to observations belonging to `entityId`. If any result has cosine distance < threshold (default 0.3), return true:
```typescript
export async function detectContradiction(
  db: Database.Database,
  entityId: string,
  factText: string,
  threshold = CONTRADICTION_DISTANCE_THRESHOLD,
): Promise<boolean> {
  const embedding = await embedText(factText);
  if (embedding === null) return false; // Can't check — Ollama unavailable, don't block

  const vec = new Float32Array(embedding);
  const rows = db.prepare(`
    WITH knn AS (
      SELECT item_id, distance
      FROM vec_embeddings
      WHERE embedding MATCH ?
        AND k = 5
        AND item_type = 'observation'
    )
    SELECT knn.distance
    FROM knn
    JOIN observations o ON o.id = knn.item_id
    WHERE o.entity_id = ?
    ORDER BY knn.distance
    LIMIT 1
  `).all(vec, entityId) as Array<{ distance: number }>;

  return rows.some(r => r.distance < threshold);
}
```

**Export: `findMergeCandidates(db, entityName): string[]`** — Query all entity names from the `entities` table and return IDs of entities where `isMergeCandidate(entityName, existingName)` is true AND the ID is different from any exact-name-match entity:
```typescript
export function findMergeCandidates(db: Database.Database, entityName: string): Array<{ id: string; name: string }> {
  const allEntities = db.prepare('SELECT id, name FROM entities').all() as Array<{ id: string; name: string }>;
  return allEntities.filter(e =>
    e.name !== entityName && isMergeCandidate(entityName, e.name)
  );
}
```

**Export: `runConsolidation(db: Database.Database): Promise<ConsolidationSummary>`** — The main batch loop:

1. Initialize summary counters: `{ totalProcessed: 0, totalExtracted: 0, totalAutoApproved: 0, totalQueued: 0, errors: 0 }`
2. Loop:
   a. SELECT `BATCH_SIZE` episodes WHERE `consolidated_at IS NULL` ORDER BY `created_at`
   b. If no rows, break
   c. Call `extractFacts(batch.map(ep => JSON.stringify({ id: ep.id, event_type: ep.event_type, payload: ep.payload, created_at: ep.created_at })))`
   d. For each extracted fact:
      - Look up existing entity: `SELECT id FROM entities WHERE name = ? AND type = ?` using fact.entity_name and fact.entity_type
      - Check for merge candidates: `findMergeCandidates(db, fact.entity_name)`
      - Check for contradiction (only if entity exists): `detectContradiction(db, entityId, fact.observation)`
      - **Route decision:**
        - If `fact.confidence >= CONFIDENCE_THRESHOLD` AND no contradiction AND no merge candidates → **auto-approve**: call `rememberEntity(db, { content: fact.observation, entity_name: fact.entity_name, entity_type: fact.entity_type, confidence: fact.confidence, relations: fact.related_entities.map(r => ({ target_name: r.name, target_type: r.type, relation_type: r.relation_type })) })` with source_type override. Note: `rememberEntity` currently hardcodes `source_type: 'agent_session'` — the consolidator should call it with a provenance override. To avoid modifying rememberEntity's signature in this plan, use the direct DB insert pattern from rememberEntity's body but with `source_type: 'consolidation'`. Alternatively, add an optional `source_type` parameter to `RememberParams` and pass `'consolidation'`. Choose the approach that minimizes code duplication (adding `source_type` to RememberParams is cleaner).
        - Otherwise → **queue**: INSERT INTO `approval_queue` with `id = nanoid()`, `item_type = 'proposed_fact'`, `item_id = nanoid()` (placeholder), `status = 'pending'`, `reason` = one of `'low_confidence'`, `'contradiction'`, `'merge_candidate'`, `'cross_session'` (use first matching reason), `metadata` = JSON.stringify of `{ fact, source_episode_ids: batch.map(e => e.id), merge_candidate_ids?: [...] }`, `created_at = new Date().toISOString()`
        - Increment appropriate counter
   e. Mark batch as consolidated: `UPDATE episodes SET consolidated_at = ? WHERE id IN (...)` using current ISO timestamp and batch IDs
   f. Increment totalProcessed by batch.length
   g. If batch.length < BATCH_SIZE, break (last batch)
3. Log summary to stderr: `console.error('[consolidation] summary:', JSON.stringify(summary))`
4. Return summary
