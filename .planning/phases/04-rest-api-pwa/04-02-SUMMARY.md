## Decisions Made

- shadcn/ui components created manually rather than via `npx shadcn@latest` CLI (interactive CLI not suitable for automated execution; manual creation is functionally identical)
- `routeTree.gen.ts` created manually — normally auto-generated by Vite plugin on first `npm run dev`; the manual version has the correct shape and will be regenerated automatically on dev start
- Radix UI primitives installed individually (@radix-ui/react-slot, separator, select, tooltip, scroll-area, scroll-area) rather than letting shadcn CLI manage them
- `pendingCount` prop on Sidebar accepts external value — TanStack Query wiring deferred to plan 03 where dashboard data fetching is implemented
