**Step 1: Create `packages/core/src/import-export.ts`.**

Define the `GraphExport` interface per locked decision:
```typescript
export interface GraphExport {
  metadata: {
    version: string;
    exported_at: string;
    entity_count: number;
    observation_count: number;
    relationship_count: number;
  };
  entities: Entity[];
  observations: Observation[];
  relationships: Relationship[];
}

export interface ImportResult {
  entities_added: number;
  entities_skipped: number;
  observations_added: number;
  observations_skipped: number;
  relationships_added: number;
  relationships_skipped: number;
}
```

**exportGraph function:**
```typescript
export function exportGraph(db: Database.Database): GraphExport
```
- Synchronous bulk SELECT on all three tables
- Entities: `SELECT * FROM entities WHERE merged_into IS NULL ORDER BY created_at`
- Observations: `SELECT * FROM observations ORDER BY created_at` (ALL including retired per locked decision)
- Relationships: `SELECT * FROM relationships ORDER BY created_at`
- Return wrapped in metadata with version `'1.0'`, exported_at, and counts

**importGraph function:**
```typescript
export async function importGraph(
  db: Database.Database,
  payload: GraphExport,
  stmts: MycoStatements,
): Promise<ImportResult>
```
Processing order per Pitfall 5: entities FIRST, then observations, then relationships.

Entity import:
- For each entity: check `stmts.selectEntityByNameType.get(entity.name, entity.type)`
- If exists: skip (increment entities_skipped)
- If not: insert using `stmts.insertEntity.run(...)` preserving original id, timestamps, metadata
- Build a map of `original_id -> new_or_existing_id` for observation/relationship mapping

Observation import:
- For each observation: look up the entity_id mapping
- Run through `classifyObservation(db, entityId, obs.content, vec, stmts)` per locked decision (dedup from Phase 19 applies)
- Get embedding via `embedText(obs.content)` for the classification
- If NOOP: skip (increment observations_skipped)
- If ADD: insert with ORIGINAL `valid_from` and `valid_until` timestamps (Pitfall 2: do NOT generate new timestamps)
- If UPDATE: retire the old and insert with original timestamps
- After insert: add to FTS index, add vec embedding if available, flag needs_embedding if not

Relationship import:
- For each relationship: map from_id and to_id through the entity mapping
- Check if relationship already exists (same from_id, to_id, type) via `stmts.selectRelationshipExists`
- If exists: skip
- If not: insert preserving original strength and reinforcement_count per locked decision (relationship strength from Phase 20 applies)

IMPORTANT: Import must use `stmts.insertObservation` with the original `valid_from` timestamp (passed as the last parameter), NOT `new Date().toISOString()`. This preserves temporal history for `as_of` queries.

**Step 2: Create `packages/core/src/format-adapters.ts`.**

Two adapters that normalize external formats to `GraphExport`:

**Mem0 adapter (`normalizeMem0`):**
```typescript
interface Mem0Memory { id: string; memory: string; user_id?: string; metadata?: Record<string, unknown>; created_at?: string; }
interface Mem0Export { results: Mem0Memory[] }

export function normalizeMem0(input: Mem0Export): GraphExport
```
- For each memory: check `metadata.entity_name` and `metadata.entity_type` if present
- If metadata has entity_name: use it as the entity
- If not: group under a catch-all entity `"mem0_import"` with type `"import_batch"` per Pitfall 3
- Map `memory` string to observation content
- Preserve `created_at` if available, otherwise use current timestamp for valid_from
- Return as GraphExport format with metadata version `'mem0-import'`

**Anthropic JSONL adapter (`normalizeAnthropicJSONL`):**
```typescript
export function normalizeAnthropicJSONL(jsonl: string): GraphExport
```
- Split on newlines, parse each line as JSON
- Filter for lines with `type === 'entity'`
- For each entity line: create an entity + observations from the `observations` string array
- Generate nanoid for each entity and observation
- Return as GraphExport format with metadata version `'anthropic-import'`

**Step 1: Add export_graph and import_graph MCP tools to tools.ts.**

Add two new `server.registerTool()` calls in the `registerTools` function:

**export_graph tool:**
- Input schema: `{}` (no parameters needed)
- Handler: call `exportGraph(db)` from `@myco/core`, return the result as JSON string in MCP content format
- Description: `'Export the entire knowledge graph as JSON. Returns all entities, observations (including retired), and relationships.'`

**import_graph tool:**
- Input schema:
  - `data: z.string().describe('JSON string or file path containing the import data')`
  - `format: z.enum(['native', 'mem0', 'anthropic']).default('native').describe('Format of the import data: native (Myco export), mem0 (Mem0 export), anthropic (MCP reference server JSONL)')`
- Handler:
  1. Determine if `data` is a file path (starts with `/` or `~`) or inline JSON
  2. If file path: read with `fs.readFileSync` (resolve `~` to homedir)
  3. Parse based on format:
     - `native`: `JSON.parse(data) as GraphExport`
     - `mem0`: `normalizeMem0(JSON.parse(data))`
     - `anthropic`: `normalizeAnthropicJSONL(data)` (raw string, not JSON.parse — it's JSONL)
  4. Call `importGraph(db, payload, stmts)`
  5. Return import result as JSON string in MCP content format
- Description: `'Import knowledge from a JSON file or string. Supports native Myco format, Mem0 format, and Anthropic MCP reference server JSONL format. Deduplicates automatically.'`

Import from `@myco/core`:
```typescript
import { exportGraph, importGraph, normalizeMem0, normalizeAnthropicJSONL } from '@myco/core';
import type { GraphExport } from '@myco/core';
```

**Step 2: Create HTTP endpoints at `packages/api-server/src/routes/io.ts`.**

Use `OpenAPIHono` and `createRoute` pattern (same as memory.ts from Plan 02):

**GET /api/export:**
- No request body
- Response: 200 with `GraphExport` schema
- Handler: `exportGraph(db)` -> `c.json(result)`
- No auth required (read-only)

**POST /api/import:**
- Request body: `{ data: object | string, format?: 'native' | 'mem0' | 'anthropic' }`
  - For native format: `data` is the `GraphExport` object directly
  - For mem0: `data` is the Mem0 export object
  - For anthropic: `data` is the JSONL string
- Response: 200 with `ImportResult` schema
- Handler: normalize based on format, call `importGraph(db, payload, stmts)`
- Auth required (write operation) — apply `apiKeyAuth()` middleware

Export as:
```typescript
export function registerIORoutes(app: OpenAPIHono, db: Database.Database, stmts: MycoStatements): void
```
