Add the following new prepared statements to MycoStatements interface AND the createStatements function:

1. **selectGrowthTimeSeries** — Daily-bucketed counts for last 30 days. SQL:
```sql
SELECT date(created_at) as day,
  SUM(CASE WHEN src = 'entity' THEN 1 ELSE 0 END) as entities,
  SUM(CASE WHEN src = 'observation' THEN 1 ELSE 0 END) as observations,
  SUM(CASE WHEN src = 'relationship' THEN 1 ELSE 0 END) as relationships
FROM (
  SELECT created_at, 'entity' as src FROM entities WHERE created_at > ?
  UNION ALL
  SELECT created_at, 'observation' as src FROM observations WHERE created_at > ?
  UNION ALL
  SELECT created_at, 'relationship' as src FROM relationships WHERE created_at > ?
) combined
GROUP BY date(created_at)
ORDER BY day ASC
```
Parameter: ISO date string (30 days ago). Returns Array<{ day: string; entities: number; observations: number; relationships: number }>.

2. **countEmbeddedObservations** — Embedding coverage. SQL:
```sql
SELECT
  (SELECT COUNT(*) FROM observations) as total,
  (SELECT COUNT(DISTINCT item_id) FROM vec_embeddings WHERE item_type = 'observation') as embedded
```
Returns { total: number; embedded: number }.

3. **countOrphanedEntities** — Entities with no relationships. SQL:
```sql
SELECT COUNT(*) as n FROM entities e
WHERE NOT EXISTS (SELECT 1 FROM relationships r WHERE r.from_id = e.id OR r.to_id = e.id)
```
Returns { n: number }.

4. **selectConfidenceDistribution** — Bucketed confidence. SQL:
```sql
SELECT
  CASE
    WHEN confidence >= 0.8 THEN 'high'
    WHEN confidence >= 0.5 THEN 'medium'
    ELSE 'low'
  END as bucket,
  COUNT(*) as count
FROM entities
GROUP BY bucket
```
Returns Array<{ bucket: string; count: number }>.

5. **countUnconsolidatedEpisodes** — Consolidation backlog. SQL:
```sql
SELECT COUNT(*) as n FROM episodes WHERE consolidated_at IS NULL
```
Returns { n: number }.

6. **selectRecentActivity** — Rich entity-level activity (replaces recentEpisodes for the activity feed). SQL:
```sql
SELECT e.id, e.name, e.type, e.confidence, e.created_at, 'created' as event
FROM entities e
ORDER BY e.created_at DESC
LIMIT 20
```
Returns Array<{ id: string; name: string; type: string; confidence: number; created_at: string; event: string }>.

Add all six to the MycoStatements interface type block (in the "Dashboard / aggregate statements" section) and to the createStatements function body.
